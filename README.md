# CALANQUE D'AZUR — The Poster for a Place That Isn't There

A travel poster for a place that isn't there: CALANQUE D'AZUR. A stone
obelisk with a seagull watches over a sunlit Mediterranean plaza — white
hillside town, blue doors, bougainvillea, café tables, sailboats in the
harbour. The place name is set into the plaza paving itself.

Entry for the [make.fun bounty "The Poster for a Place That Isn't
There"](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## Run

```sh
python3 main.py
```

Writes the poster to `/output/entry.png` (1024x1024 PNG, deterministic —
every run writes the same bytes).
